UNSAIDfor agents

Call it from your agent.

One tool, unsaid_places(loves, city). It crosses out every place the AIs in its data name for that city (each answer is stamped with its provider and model), and returns up to seven that Qloo ranks for those loves, each with its Qloo ID, “#k for you · #j for anyone”, the love behind it and how many AI answers named it.

curl


    
loves is a JSON array of up to three [text, type] pairs, the form above. Give a type for a dish ("tag") and for a place ("place"): untyped, "rib tips" can resolve to a restaurant. Types: artist, movie, tv_show, book, podcast, videogame, brand, place, tag. Plain text, {"text": "...", "type": "movie"} and chips from /api/resolve also work. The reply is NDJSON; the last line is {"type":"done","result":{...}}. GET /api/health never needs the token.


    
Token

    
Until 30 Oct 23:45 ET the API needs a token. It is in the Devpost testing instructions. After that the token is removed and the API is open, rate-limited to 3 fresh runs per hour per address. Repeat queries are cached and free.

    
Send it as Authorization: Bearer …, as X-Unsaid-Token: …, or as &token=…. In a browser, add ?token=… to this site’s address and the page passes it on.


    
MCP

    
The MCP server is one Python file, standard library only. By default it calls this site’s API, so your agent gets the same live Qloo ranks and the same dated AI answers as this page. You don’t need a Qloo key.

    
Claude Code:

    
claude mcp add unsaid -e UNSAID_MODE=remote -e UNSAID_TOKEN=<token> -- python3 -I /path/to/unsaid/agent/unsaid_mcp.py

    
Claude Desktop (claude_desktop_config.json):

    
{
  "mcpServers": {
    "unsaid": {
      "command": "python3",
      "args": ["-I", "/path/to/unsaid/agent/unsaid_mcp.py"],
      "env": { "UNSAID_MODE": "remote", "UNSAID_TOKEN": "<token>" }
    }
  }
}

    
The token is the one from the Devpost testing instructions. After 30 Oct 23:45 ET, leave it out. In remote mode the server lists one tool, unsaid_places(loves, city). Pass loves as [text, type] pairs. It covers St. Louis and New York, the cities where we collected what the AIs say. With your own QLOO_API_KEY, UNSAID_MODE=live runs the engine locally and also lists qloo_places(loves, city): Qloo’s top 50 for the same loves, with nothing crossed out. That tool is the meter’s “with” arm.


    
One real run

    
claude -p "I love Frankie Beverly & Maze, The Original Kings of Comedy and rib tips. Where should I go in St. Louis tonight?" \
  --mcp-config agent/mcp.json --allowedTools mcp__unsaid__unsaid_places

    
agent/mcp.json sets UNSAID_MODE=remote and reads UNSAID_TOKEN from your shell. Replace /path/to/unsaid in it with the path to your clone first.
